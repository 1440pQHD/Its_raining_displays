# Its_raining_displays
A 2D game written in Python where the protagonist, a high school student, tries dodging falling interactive displays while collecting various canteen items!

# The story behind the idea
You're probably asking yourselves where I got this odd idea from, for a game where you are dodging random Samsung electronic displays and collecting odd-looking food items. To answer that, you first need to know one thing: I live in Greece. Our high schools recently got an upgrade from regular whiteboards to fancy digital ones. Samsung-branded ones specifically. Most of the students here hate these. Why, you may ask? Well, because ever since these pretty expensive pieces of technology got installed, the school administration has been PARANOID. We aren't allowed to stay in class during recess; We aren't allowed to use them ourselves; Most of the teachers -especially older teachers- refuse to learn how to use them and notably the money that was used to acquire them could have been used in much more meaningful ways.

That's how I came up with the main antagonist of my game: "The evil electronic white-board"

# The biggest challenge I faced
This is easy to answer: Asset design. Let's be clear, I'm terrible at drawing. I couldn't draw a properly shaded ball to save my life. That's why I decided to go with Pixel art (more like Pixel something that vaguely resembles art).
